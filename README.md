## 简介

这是阿寂的个人主页，采用 Python 内置 HTTP 服务器在本地提供服务，并通过 Cloudflare Tunnel 安全地将本地服务暴露至公网。

## 技术栈

- 运行时：Python 3（http.server 模块）
- 服务暴露：Cloudflare Tunnel（cloudflared）
- 前端：纯 HTML + CSS + JavaScript（未使用构建工具）
